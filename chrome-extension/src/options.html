📣 PrismAAC Reading Assistant

A free Read & Write alternative — speak as you type, in any text field, on any site.
Behavior
Translate while speaking

When set, the overlay shows BOTH the source line (small italic) and the translated line (with word highlight as it's spoken). Translation uses Google's free public endpoint over HTTPS — no API key, but the source text leaves your device for that one call.

Voice
Per-site
Settings sync across your Chrome profile via chrome.storage.sync. The extension never sends typed text off-device — Web Speech runs natively in your browser. Source code: github.com/dcostenco/prism-aac
