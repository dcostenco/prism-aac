# README screenshot provenance

The web images in this directory were captured from
[Prism AAC](https://synalux.ai/prism-aac) on October 26, 2026, with WebKit.
They show an isolated, signed-out visitor with English labels, local display
preferences, and no personal messages or contacts. The cloud-preview notice is
part of the real interface. Optional panels were opened through the toolbar.
The emergency image shows the confirmation dialog; Send was never pressed.

Every web capture checks the installed picture-pack version against
[the current manifest](../../../constants/generated/picturePack.json):
`294639f647b616cc5c1b4d7bff31f063dd1cc2ff9d889f369265cfdea538da6d`.
Rendered pictures must load successfully from the app's local pack. See
[picture attribution](../../../public/symbols/ATTRIBUTION.txt) for its source.
No picture, account, subscription or camera result was mocked.

Each web PNG has a JSON receipt containing its capture time, run, viewport,
picture-pack version and SHA-256. The captures use DPR 1:

| Surface | CSS viewport | Visible state |
|---|---|---|
| Phone portrait | 390 × 844 | Picture board; light or dark/high contrast |
| Phone landscape | 844 × 390 | Typing mode with prediction pictures |
| Tablet portrait | 1032 × 1376 | Picture board, schedule or games |
| Tablet landscape | 1376 × 1032 | Picture board, dark/high contrast or feature panel |

The landscape-phone example deliberately documents Typing mode. An initial
Picture-mode capture failed the occlusion check and was rejected; this update
does not claim to fix that separate layout issue.

## Native images

`native-iphone-typing.png` and `native-ipad-typing.png` come from the October 25
iOS 26.2 simulator runs for version 1.9.3 (56). They show the retained test
message “hi” in Typing mode. [Native receipts](native-captures.json) bind these
images to the tested commit and their hashes. They are simulator captures
using a local fixture, and do not demonstrate a real purchase or restore.
The README's separate Watch image remains explicitly labeled build 1.4.0.

## Verification and reproduction

The capture spec uses the shared `safeScreenshot()` validator: URL, error UI,
loaded content, blank-image and critical-control occlusion checks precede each
PNG write. The PNG geometry verifier checks the declared viewport and DPR.
The images were also opened and visually reviewed.

The reference is the current app's labeled board and panel controls. Compared
with the retired README screenshots, the new boards show Prism AAC's current
colored figures, red-cube prediction pictures and complete vocabulary labels.
Feature panels show their actual empty or settings states, rather than the old
board screenshots with feature titles overlaid on top. Camera settings are
labeled as settings, without claiming that a scene was detected.

From the repository root, with dependencies and WebKit installed:

```sh
BASE_URL=https://synalux.ai bash scripts/playwright-watchdog.sh e2e/capture-readme-pictures.spec.ts --project=ipad-13-land --workers=1
```

This overwrites only this directory's generated web captures and receipts.
Native images require their separately documented simulator runs. Older
screenshot files remain in the repository for history; the updated README
references use this directory. The linked historical preview video has not
been regenerated by this screenshot update.
