## 1. TTS streaming silent / wrong pitch ✅

**Reports:** "voice is not streaming", "morning routine 2× faster", "chipmunk", "still broken" (4×), "full silence".

**Root cause:** Web Audio's `BufferSource.start()` doesn't throw on a suspended `AudioContext` — audio queues silently. Earlier fix-flips also revealed Inworld TTS-2 ignores SSML `rate=`, so rate-conversion experiments were chasing the wrong root cause.

**Fix:** `ctx.state === 'running'` guard in `services/azureTTS.ts` (commit `8a7943f`), gated rate clamp `[0.5, 2.0]` pass-through (commit `0c22eb4`). Build switched from Turbopack to webpack so Serwist actually regenerates `public/sw.js` (commit `107bb95`) — this was why earlier fixes never reached the deploy.

**Verification:** `scripts/tts-live-diag-webkit.mjs` against `synalux.ai/prism-aac` with Vineland-3 + multi-lang sample → `stateAtStart=running`, `gain=1`, `sourceStartCount=1`, `onended=646ms`. Romanian routes to Azure `ro-RO-AlinaNeural`; rate=1.00 across all 4 langs.

## 2. Math hint replies in English when Romanian selected ✅

**Report:** RU→RU pair, math tutor's Hint bubble came back in English.

**Root cause:** Two-layer bug.
1. `MathTutorTool` was reading `settings.language` (UI lang) instead of `outputLanguage`.
2. `synalux-private` `prism-aac/chat` route was hardcoding `system: AAC_SYSTEM` and silently filtering out the client's `role:'system'` messages.

**Fix:**
- prism-aac commit `3a68a09`: tutor uses `outputLanguage`, appends `Respond in {Lang}. Use natural {Lang} phrasing.` to user prompt tail.
- synalux-private commit `b2d70b0c`: `combinedSystem(messages)` merges client system under `CLIENT CONTEXT` header, AAC_SYSTEM still wins on conflicts.

**Tests:** `tests/math-tutor-output-language.test.tsx` (5 cases, prism-aac), `route.test.ts` (4 new cases pinning combinedSystem contract, synalux).

## 3. Translation RU→IT mixed-language mush ✅

**Report:** typed "хочу больше свободы" with RU→IT, output bar showed "Want più свободы".

**Root cause:** `getPhraseText('cw-want', 'it', 'Want')` returns the English fallback `'Want'` because `T['cw-want']` has no `it` entry. The dict builder registered that English string as the IT translation.

**Fix:** prism-aac commit `74d36fe` — `getWordDict` now skips a phrase pair when the target lang's `getPhraseText` output equals the English fallback. Added Italian/Dutch/Polish/Turkish/Swedish/Norwegian/Danish/Finnish/Czech/Greek/Hungarian/Hebrew/Hindi/Vietnamese/Thai/Indonesian/Tagalog to `LANG_NAMES` + `SCRIPT_FOR_LANG`.

**Tests:** `tests/translateService.test.ts` (7 cases pinning the no-leak invariant).

## 4. PDF Reader "could not be read: undefined is not a function" on Vineland-3 ✅

**Report:** Clinical assessment PDF (Vineland-3, 35 pages), every page errors. Mortgage-form PDF works fine.

**Root cause:** pdfjs 5.x `getTextContent()` default normalization walk trips a `for…of` over an undefined collection on tagged-PDF marked content (Pearson Q-global reports + similar clinical PDFs). Surfaces in Safari as the cryptic minified error.

**Fix:** prism-aac commit `1c4fad9` — pass `{ includeMarkedContent: false, disableNormalization: true }` to `getTextContent`, defensive iteration with `typeof str === 'string'` check, per-phase error reporting (`getPage` / `getTextContent` / `mapItems` / `cleanup`) so future regressions are diagnosable.

**Verification:** `scripts/pdf-repro.mjs` against the user's actual `/Users/admin/Downloads/Vineland-3-Comprehensive-Report_80259322_1778166067638.pdf` on the live deploy → all 5 sample pages extract clean text.

## 5. Service Worker stuck serving stale chunks ✅

**Reports:** "still broken", "same", "reloaded - full silence" — repeatedly. User's tab kept loading Apr-30 SW + cached chunks even after Cmd+Shift+R.

**Root cause:** Cmd+Shift+R doesn't unregister Service Workers in Safari. The Apr-30 SW intercepted fetches and served stale precached HTML/chunks.

**Fix:** prism-aac commits `a52683d`, `f24bd48` — inline `<script>` in `app/layout.tsx` that runs FIRST on every page load. Compares `SW_KILLSWITCH_VERSION` against localStorage. On mismatch: unregisters every SW under the origin, deletes every Cache Storage entry, writes the new version, reloads.

**End-user impact:** zero manual intervention. Bump `SW_KILLSWITCH_VERSION` in `app/layout.tsx` whenever a deploy needs a forced client-side reset.

## 6. Vercel build pipeline didn't include latest commits ✅

**Reports:** "I lost 2 hours". User clicked "Redeploy without cache" repeatedly; each attempt rebuilt the same older commit.

**Root cause:** Vercel's Redeploy button rebuilds the SAME commit as the source deploy, not main HEAD. Combined with Turbopack production builds silently skipping Serwist's webpack plugin, the committed Apr-30 `public/sw.js` was served for every "redeploy".

**Fix:** prism-aac commit `107bb95` — `package.json` build script switched to `next build --webpack` so Serwist regenerates `public/sw.js` every build. Webpack `node:` scheme handling for Pyodide. Pyodide added to `serverExternalPackages`. Home page `force-dynamic`. MathTutorTool wrapped in `next/dynamic({ssr:false})`.
