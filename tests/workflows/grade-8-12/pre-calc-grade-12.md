# Pre-Calculus — Grade 12

Real-classroom word problems. Solution style mirrors the reference
PDF: every transformation on its own line, final answer with units
or labeled value.

Math panel categories used: `main`, `adv-math` (², ³, √, ∛, log, ln,
π, x, y, m, n, !, ≈), `misc-math` (∞, →, ⇒), `physics` for θ.

1. Logarithm — solve log₂ ( x ) = 5.

   log₂ ( x ) = 5
   x = 2⁵
   x = 32

2. Exponential growth — population doubles every 10 years, P₀ = 1000.
   Find P at t = 30 years.

   P = P₀ × 2^(t÷10)
   P = 1000 × 2^(30÷10)
   P = 1000 × 2³
   P = 1000 × 8
   P = 8000 people

3. Trig — find sin(30°) + cos(60°).

   sin ( 30° ) = 0.5
   cos ( 60° ) = 0.5
   sum = 0.5 + 0.5
   sum = 1.0

4. Solve quadratic — x² − 5 x + 6 = 0.

   x² − 5 x + 6 = 0
   ( x − 2 ) ( x − 3 ) = 0
   x = 2 , x = 3

5. Sequence — arithmetic, a₁ = 4, d = 3. Find a₁₀.

   aₙ = a₁ + ( n − 1 ) × d
   a₁₀ = 4 + ( 10 − 1 ) × 3
   a₁₀ = 4 + 27
   a₁₀ = 31

6. Limit — evaluate lim ( x → 2 ) of ( x² − 4 ) ÷ ( x − 2 ).

   ( x² − 4 ) ÷ ( x − 2 )
   = ( x − 2 ) ( x + 2 ) ÷ ( x − 2 )
   = x + 2
   x → 2
   limit = 4

7. Combinations — how many ways to choose 3 students from 8?

   C ( 8 , 3 ) = 8 ! ÷ ( 3 ! × 5 ! )
   = ( 8 × 7 × 6 ) ÷ ( 3 × 2 × 1 )
   = 336 ÷ 6
   = 56 ways
