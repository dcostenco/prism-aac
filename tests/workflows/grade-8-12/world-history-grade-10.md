# World History — Grade 10

Real-classroom timeline / source-analysis problems. Solution style
mirrors the reference PDF: every step on its own line, final answer
is a labeled date / period / event.

Math panel categories used: `main`, `history` (BCE, CE, BC, AD, c.,
fl., –, →, century ordinals 1st–21st, period names, locale events).

2. Date arithmetic — how many years from 1453 (fall of Constantinople)
   to 1492 (Reconquista).

   end = 1492 CE
   start = 1453 CE
   Δ = 1492 − 1453
   Δ = 39 years

2. Centuries — what century is 1776 in?

   year = 1776 CE
   century = ( 1776 − 1 ) ÷ 100 + 1
   century = 17.75 + 1
   century = 18th century

3. BCE → CE span — Roman Republic 509 BCE to Roman Empire fall 476 CE.

   start = 509 BCE
   end = 476 CE
   span = 509 + 476
   span = 985 years

4. WWI duration.

   start = 1914
   end = 1918
   Δ = 1918 − 1914
   Δ = 4 years

5. WWII duration.

   start = 1939
   end = 1945
   Δ = 1945 − 1939
   Δ = 6 years

6. Cold War span — 1945 (WWII end) to 1989 (Berlin Wall fall).

   start = 1945
   end = 1989
   Δ = 1989 − 1945
   Δ = 44 years
   period = Cold War

7. Cause-and-effect chain — sequence the French Revolution events.

   1789 → storming of Bastille
   1789 → declaration of rights
   1793 → execution of Louis XVI
   1799 → Napoleon coup
   period = French Revolution
