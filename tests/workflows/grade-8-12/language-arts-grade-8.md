# Language Arts — Grade 8

Real-classroom analysis problems. Solution style mirrors the
reference PDF: every step on its own line, final "answer" is a
labeled tag set.

Math panel categories used: `language-arts` (N, V, ADJ, ADV, PRON,
PREP, CONJ, ART, DECL, INT, IMP, EXCL, COMP, CPLX, MLA, APA, p., pp.).

1. Tag parts of speech — "The quick brown fox jumps over the lazy dog."

   The     = ART
   quick   = ADJ
   brown   = ADJ
   fox     = N
   jumps   = V
   over    = PREP
   the     = ART
   lazy    = ADJ
   dog     = N
   sentence type = DECL

2. Identify sentence type — "Stop running in the hall!"

   sentence = "Stop running in the hall!"
   no subject visible
   command form = imperative
   end punctuation = !
   type = IMP

3. Find the subject and verb — "After the rain stopped, the children
   played outside."

   independent clause = "the children played outside"
   subject = children ( N )
   verb    = played ( V )
   dependent clause = "After the rain stopped"
   type = CPLX

4. Compound vs. complex — "I studied, and I passed the test."

   clause 1 = "I studied"
   clause 2 = "I passed the test"
   conjunction = and ( CONJ )
   both independent
   type = COMP

5. MLA in-text citation — quote from page 47 of a novel by Lee.

   author = Lee
   page = 47
   citation = ( Lee 47 )
   style = MLA

6. APA in-text citation — Smith ( 2019 ), page 12.

   author = Smith
   year = 2019
   page = 12
   citation = ( Smith , 2019 , p. 12 )
   style = APA

7. Pronoun reference — "Maria gave Sara her book." Whose book?

   antecedent candidates = Maria , Sara
   her = ambiguous PRON
   revision : "Maria gave Sara Maria's book."
   clarity = improved

NOTE: This document must be reviewed and individualized by the
classroom teacher.
