# Biology — Grade 9

Real-classroom word problems. Solution style mirrors the reference

or labeled value.

1. Punnett square — Bb × bb cross. Find the genotype ratio.

   Bb × bb
   offspring = Bb , Bb , bb , bb
   Bb = 2 ÷ 4
   bb = 2 ÷ 4
   ratio = 1 : 1

2. Phenotype probability — Aa × Aa cross. Find P(dominant phenotype).

   Aa × Aa
   genotypes = AA + 2 Aa + aa = 4
   dominant = AA + 2 Aa = 3
   P ( dom ) = 3 ÷ 4
   P ( dom ) = 75 %

3. Transcription — DNA template strand A T G C C A. Write the mRNA.

   DNA = A T G C C A
   pairing : A → U , T → A , G → C , C → G
   mRNA = U A C G G U

4. Translation — mRNA strand of 18 bases. How many amino acids?

   bases = 18
   codon = 3 bases
   amino_acids = 18 ÷ 3
   amino_acids = 6

5. Population growth — bacteria double every 20 min, start with 100.
   How many after 1 hour?

   doublings = 60 ÷ 20
   doublings = 3
   N = 100 × 2³
   N = 100 × 8
   N = 800 cells

6. Test cross — purple ( P_ ) × white ( pp ). Offspring are 50 %
   purple, 50 % white. Find the unknown parent's genotype.

   purple × white = Pp , Pp , pp , pp
   ratio observed = 1 Pp : 1 pp
   parent = Pp ( heterozygous )

7. Codon coding — RNA segment AUG GCA UAA. Translate using the
   start / stop convention.

   AUG = start ( Met )
   GCA = Ala
   UAA = stop
   protein = Met − Ala
